# 0001. 프런트엔드·백엔드 병합 범위

- 날짜: 2026-10-28
- 상태: 승인

## 결정

기존 FastAPI와 워커, MongoDB 저장 구조를 유지하고 React 프런트엔드는 독립 배포한다. 프런트엔드는 환경 변수로 데모 모드와 API 모드를 전환한다.

공통 PRD의 파일 업로드·진단·정제·다운로드 흐름을 우선 통합한다. 기존 민원 분석, 병합, 매핑 제안 API는 삭제하지 않고 후속 화면 통합 대상으로 유지한다. 새 API나 컬렉션을 추가할 때는 CLAUDE.md의 기준 문서 우선순위를 계속 따른다.

## 이유

두 저장소의 독립 개발 이력을 보존하면서 단계적으로 병합하고, 백엔드가 준비되지 않은 Vercel 배포에서도 데모 화면을 계속 확인하기 위해서다.
